# Habits Shape Life plugin for Claude

Ask Claude about your own Habits Shape Life records. This plugin connects Claude to the read-only Habits Shape Life remote MCP server and adds skills for reading the records and analyzing them: calorie balance and weight trends, and reviews of a week or month compared with the period before.

The plugin files are published here after they pass review. Learn more at https://habit-shape-life.pages.dev/en/about/.
